# `sets/` — Complete-look sets

Put whole-ensemble catalogs here (outfit + shoes + jewelry + vibe as one
ready-to-use prompt/item), grouped by intended gender:

| Folder | Node category | Use for |
|--------|---------------|---------|
| `sets/female/` | `🧙 Wizdroid/Presets/Sets/Female` | Female complete looks (dresses, Indian sets, Bollywood 80s, …) |
| `sets/male/` | `🧙 Wizdroid/Presets/Sets/Male` | Male complete looks |
| `sets/unisex/` | `🧙 Wizdroid/Presets/Sets/Unisex` | Gender-neutral looks (goth, characters, anime cosplay, …) |

Each folder has its own README. Same JSON schema as always.
