# `sets/` — Complete-look sets

Put whole-ensemble catalogs here (outfit + shoes + jewelry + vibe as one
ready-to-use prompt/item), grouped by intended gender:

| Folder | Category in **🧙 Preset** | Use for |
|--------|---------------------------|---------|
| `sets/female/` | `sets/female` | Female complete looks (dresses, Indian sets, Bollywood 80s, …) |
| `sets/male/` | `sets/male` | Male complete looks |
| `sets/unisex/` | `sets/unisex` | Gender-neutral looks (goth, characters, anime cosplay, …) |

Each folder has its own README. Same JSON schema as always.
