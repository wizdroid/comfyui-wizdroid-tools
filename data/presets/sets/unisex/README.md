# `sets/unisex/` — Gender-neutral complete-look sets

Each catalog here becomes its own node under `🧙 Wizdroid/Presets/Sets/Unisex`.

Present catalogs (cover both male and female characters):

- `characters.json` — Character Set (Batman, Wonder Woman, anime characters, …)
- `anime_cosplay.json` — Anime Cosplay Set (Goku, Sailor Moon, …)

Both are formatted as cinematic cosplay portraits. Same JSON schema as before
(`label`, `items`, `output_style`, …).
